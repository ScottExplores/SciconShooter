  attached Weekly Run strip, ship with previous/next controls, connect pill,
  Campaign Mission label, START MISSION, and bottom navigation. The phone drops
  the wordmark; the unframed desktop deck retains the original large brand and
  two-column layout. The existing campaign callback still launches the mission.
- `components/revamp/HomeDailyGift.tsx`: original Daily Gift/achievement side-tab
  art, labels, reward routing, and onboarding anchor. On phones it is anchored
  beside the ship so it cannot cover the funding card or Weekly Run. Desktop
  retains its viewport-edge anchor outside the hero's backdrop filter.
- `styles/revamp-home.css`: scoped home text-fit corrections, original home fonts,
  two-column leader/score arrangement, readable long proposal copy, and original
  dot pager in a separate row to avoid overlapping the slide's button. Short
  phones get a bounded ship track so START MISSION fits above the dock. The
  optional large desktop deck can scroll instead of clipping its navigation.
- Frontier Log/research/goals and the additional Weekly Competition panel now
  live in **More**. Their actions and data remain connected. Signals, preview
  badge, and unlimited-practice label are preserved.
- `styles/revamp-layout.css`: remove the superseded home rearrangement; keep H's
  Trophy, More, scrollbar, and other-screen readability fixes. H's shared ship
  bob/thruster, entrance, press feedback, and reduced-motion behavior remain.
  Home adds a gentle funding-title shimmer and launch glow without layout motion.
- `tools-revamp/qa/ui-audit.mjs`, D/E optional browser smokes: navigate through
  More to reach the relocated panels. No screen cases, audit checks, or gates
  were removed. The H-specific onboarding/reward tests now assert the restored
  side-tab contract, and the G-era action-label assertion follows START MISSION. `tests/startScreen*.test.cjs` remains unchanged.
- `styles/tailwind.generated.css`: regenerated by the normal build.

All implementation hooks in the shared `StartScreen.tsx` are marked
`REVAMP(K)`. There are no hooks in `services/gameLogic.ts`,
`services/pixi/PixiGameRenderer.ts`, or `App.tsx`.
