# Breakwater scenery — retained for future missions

The opening five campaign missions use their original environment profiles again:
Open Orbit, Citation Storm, Paywall Siege, Open Galaxy, and Bastion Protocol.
Only scenery assignments were restored; the newer Breakwater combat encounters remain.

These newer assets are intentionally preserved, not obsolete or safe to delete:

- `far-space.png`: shared distant-space layer.
- `approach.png`: orbital approach, catalog ID `breakwater-approach`.
- `wreckfield.png`: salvage field, catalog ID `breakwater-wreckfield`.
- `gate.png`: station gate, catalog ID `breakwater-gate`.

Their asset constants, catalog entries, and Pixi environment profiles remain registered.
To reuse one later, assign its background ID to the intended mission and its waves.
