# Scicon Mini Squadron Pack v1

Ten miniature companion ships for squad selection and escort flight.

Neutral gray hulls are retinted onto the research ship's navy and cyan ramp so the squadron reads as lab equipment rather than unrelated toys. Saturated role lamps stay on each ship. Runtime flight adds the engine plume, muzzle flash, and banking; these PNG frames stay the hull.

Each ship includes three transparent 256x256 PNG frames, a 768x256 horizontal
sprite sheet, and a ping-pong GIF preview. Frame order is `neutral`, `flex-in`,
`flex-out`. The hull stays centered and fixed; only small side mechanisms and
core lighting change. Runtime animation should use the PNG frames, not the GIF.
