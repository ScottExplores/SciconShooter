# Scicon Defeated Banner

This pack is a layered, animation-ready defeat announcement. Use the PNG parts
and `animation-manifest.json` at runtime. The GIF and sequence PNG are approval
and Sprite Gallery previews, not the production animation format.

The live hold loop combines slight independent torn-wing movement, opposing
warning-rotor turns, traveling light scans, weak emergency flicker, and a very
small hover. Keep `DEFEATED` as live UI text.
