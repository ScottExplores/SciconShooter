# Legacy weapon effects

The ResearchHub Signature Move frames in this directory are unmodified PNG
frames from the Legacy Collection's `Assets/Misc/Warped shooting fx` pack. The
collection distributes these assets under its included CC0 public license.

Runtime mapping:

- `research-spark`: `spark/Sprites/spark-preview1.png` through frame 5
- `research-bolt`: `Bolt/Sprites/bolt1.png` through frame 4
- `research-charge`: `charged/Sprites/charged1.png` through frame 6
- `research-impact/hits-1` through `hits-4`: the matching numbered `hits`
  sprite folders (5, 7, 5, and 7 frames respectively)

The files are checked into the project so the game and production build do not
depend on a developer's local Legacy Collection checkout.
