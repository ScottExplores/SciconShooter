# Pixi gameplay assets

The terrain, jet, thruster, and explosion sprites in this directory are adapted
from the CC0 Legacy Collection under `SpaceShipShooter`, `Warped Vehicles`, and
`Explosions pack`. They are checked into the project so gameplay does not depend
on external files.

The five-frame `effects/boss-damage` sequence comes from the CC0
`SpaceShipShooter/Sprites/Explosion` set and is reserved for boss armor breaks,
detached parts, and staged boss destruction.

The escort ship sprites are original Scicon Shooter assets generated for this
project and cleaned into transparent pixel-art PNGs.

The Paywall Decimator boss parts, damage frames, rays, bolts, and thrust are
adapted from the CC0 Legacy Collection `top-down-boss` set. The other layered
boss damage sheets are original Scicon Shooter assets generated for this
project, chroma-keyed to transparency, and normalized with
`tools/split-boss-damage-sheet.py`.
