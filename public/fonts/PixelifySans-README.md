# Pixelify Sans

Unmodified variable font (weights 400–700), bundled locally so menus render offline.

Source: https://github.com/google/fonts/tree/main/ofl/pixelifysans

Copyright 2021 The Pixelify Sans Project Authors.
Distributed under the SIL Open Font License 1.1; see `PixelifySans-OFL.txt`.

Used for short game headings and labels. Long descriptions retain the existing readable body font.
