# Play Console answers

Use these answers for the SciCon Shooter Play app, package `xyz.sciconshooter.play`. They describe the Trusted Web Activity on `https://play.sciconshooter.xyz`, not the browser site on `www.sciconshooter.xyz`.

## Ads

Does the app contain ads? No.

## App access

All functionality is available without login, password, or special access. No credentials are required. Reviewers can play immediately.

## Target audience and content

Target age: 13 and older.
The app is not directed at children under 13.
Do not appeal to children.
No ads.

## Data safety

Data is collected. It is not sold. It is not shared for advertising.

Collected, all optional except ordinary connection logs from opening the game:

| Data | Collected | Shared | Purpose | Optional |
| --- | --- | --- | --- | --- |
| App interactions (page views, anonymous play events) | Yes | No | Analytics, app functionality | Analytics runs when the game is opened |
| Crash and diagnostics, when a report includes them | Yes | No | Analytics, app functionality | Yes, only if the player submits a report with diagnostics |
| Name (pilot name on a submitted score, or text the player types into feedback) | Yes | No | App functionality | Yes |
| Financial, payment, or purchase history | No | | | |
| Precise or approximate location | No | | | |
| Contacts, photos, audio, files | No | | | |
| Health, messages, web browsing | No | | | |
| Advertising ID | No | | | |

A random device-local identifier is stored only as a one-way hash for anonymous measurements. It is not the Android advertising ID.

Data is encrypted in transit (HTTPS).
Players can request deletion by emailing sciconshooter@gmail.com. See the privacy policy.

Processors: Vercel (hosting and cookieless page views), Supabase (leaderboard and reports, if those server variables are configured), Resend (feedback email to the developer). Research proposal pages are fetched over HTTPS.

The app does not let users create an account.

## Content rating (IARC)

Category: Game.

Violence: mild fantasy or sci-fi violence. Players shoot stylized drones and bosses. No blood, no gore, no realistic human injury.
Sexual content: none.
Language: none.
Controlled substance: none.
Gambling: none. No wagering, no loot boxes, no purchases.
Users interact: a player may submit a pilot name and score to a leaderboard, and may send feedback. There is no chat and no user-to-user messaging.
Shares location: no.
Digital purchases: none.
Unrestricted internet: the app loads its game from the web and can open a research proposal page.
Recommended age: 13+.
