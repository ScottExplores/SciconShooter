# Base Builder Growth Loop

Updated: July 16, 2026

## Product thesis

Keep Scicon Shooter a game first. The durable Base-native loop is:

`guest play -> repeat competition -> optional onchain record/ship -> transparent weekly science allocation outcome`

The product should be described as a DeSci-inspired arcade game where play can help direct RSC funding credits toward eligible science proposals. Do not imply that a proposal was funded until the allocation is confirmed.

## Weekly review - Monday

1. Read Base Build announcements, current funding requests, docs changes, and reward opportunities.
2. Record weekly active players, game starts, completed runs, D1/D7 retention, wallet connections, mint conversion, repeat minters, attributed transactions, and sponsored gas.
3. Record the full science outcome: finalized winner, proposal selected, allocation status, and confirmed transaction when available.
4. Compare the strongest acquisition post with actual game starts and useful player feedback.
5. Ask one focused public question in a relevant Base builder conversation; never paste generic promotion.
6. Choose one product or marketing experiment for the week and define its success metric before shipping.

## Monthly decision rules

- Keep the game-first positioning if players start and replay even when they do not mint.
- Improve onboarding before adding more token mechanics if first-run completion or D1 retention is weak.
- Improve the ownership/reward explanation if play is healthy but mint conversion is weak.
- Expand the science-allocation story if transparent weekly outcomes generate more qualified engagement than generic gameplay posts.
- Do not add a token, prediction market, or financial feature only to match a funding theme. Add one only when it makes the player loop better and has a clear compliance review.

## Evidence for the next application

Maintain a one-page monthly scorecard with:

- attributed Base transactions and unique transacting users
- optional mint conversion and repeat ownership behavior
- community feedback incorporated into releases
- science proposals selected and allocations confirmed
