# Scicon Shooter community support playbook

## Canonical channels

- Game updates: `https://x.com/SciconShooter`
- Play: `https://www.sciconshooter.xyz/`
- Support email: `sciconshooter@gmail.com`
- Product reports: **More -> Feedback** or **More -> Report a Bug** in the game

The in-game report is the primary support record because it creates a Report ID and can include bounded diagnostics. Email is the escalation path for wallet and transaction cases that need a public transaction hash attached. X is for announcements, status updates, and general questions; it is not a private transaction-support system.

## Support triage

1. Ask the player to submit an in-game report and keep the Report ID.
2. For wallet or purchase issues, ask for the Report ID, public wallet address, public transaction hash, device/browser, and approximate time.
3. Check the owner-only report log and chain explorer before making a claim about payment or entitlement state.
4. State what is observed, what is still being checked, and the next update time.
5. Never promise a refund, reversal, replacement entitlement, or funding outcome without verified authority and evidence.

## Security rules

- Never request or accept a recovery phrase, private key, password, one-time code, or remote-access session.
- Never ask a player to send funds to prove ownership or unlock support.
- Do not troubleshoot account-specific wallet issues in public X replies or public Discord channels.
- Treat direct messages claiming to be staff as untrusted until identity is verified through the official account.
- Link only to `sciconshooter.xyz`, `x.com/SciconShooter`, official Base explorers, and other explicitly verified project resources.

## Discord launch gate

Do not open a public Discord server until two human moderators can cover reports and remove impersonation or wallet-drain scams. Start without third-party bots or wallet verification.

Recommended initial channels:

- `#start-here`: rules, official links, anti-scam warning
- `#announcements`: read-only release and competition updates
- `#game-updates`: shipped changes and known issues
- `#scores-and-clips`: player runs and weekly competition discussion
- `#feedback`: ideas and product discussion
- `#bug-reports`: directs players to the in-game report flow
- `#wallet-help`: public intake only; move account-specific details to email
- `#general`: community discussion

Recommended initial roles:

- `Founder`: account owner only
- `Moderator`: trusted human support and moderation
- `Pilot`: ordinary community member
- `Weekly Champion`: manually assigned after finalization, never from a provisional leaderboard

## Voice

Be direct, calm, and specific. Acknowledge the exact problem, ask for the smallest useful evidence, avoid jargon, and never imply Scicon Shooter is an official ResearchHub product. Describe proposal selection separately from confirmed funding.

## X response workflow

Codex can monitor public activity and prepare a prioritized response queue, but public replies require owner approval at action time. Each proposed response must include the source URL, final copy, response goal, and whether a game or support link is necessary.

- Reply first to direct player questions, reproducible bug reports, score posts, and actionable feedback.
- Thank beta testers by naming the specific observation or change they helped surface.
- Do not argue with hostile accounts, amplify scams, or respond to generic engagement bait.
- Never use automated likes, follows, keyword replies, repeated templates, or unsolicited bulk outreach.
- For wallet or transaction cases, give the official in-game reporting path and support email, then stop public troubleshooting.
